# Grid UI
 
A collection of interactive front-end UI components and layout experiments, inspired by Dribbble design concepts. Built as hands-on practice in responsive design, animation, and interactive front-end development.
 
## ✨ UI Components
 
- **Animated hover effects / interactive cards** — Cards and UI elements that respond to user interaction with smooth, hover-triggered transitions.
- **Sliders and carousels** — Custom-built sliders for cycling through content and images.
- **Animated buttons and toggles** — Interactive buttons and toggle switches with built-in motion feedback.
- **Image galleries/grids with dynamic layouts** — Responsive image grids that rearrange based on screen size and content.
## 🛠 Tech Stack
 
- HTML5
- CSS3
- JavaScript
- GSAP (GreenSock Animation Platform)
